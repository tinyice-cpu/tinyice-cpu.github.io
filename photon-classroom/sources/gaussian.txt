## 2.3.2高斯光束的特性

式（2.3.10)充分表现出高斯光束的特点，另外关系式（2.3.6）～（2.3.9)可确定高斯光束的特性。下面进一步细致地分析高斯光束，同时讨论式(2.3.10)中各因子的物理意义。

1．光强

光强 $I ( \boldsymbol { r } ) = \left| U ( \boldsymbol { r } ) \right| ^ { 2 }$ ，高斯光束的光强是轴向距离z与径向距离 $\rho = ( x ^ { 2 } + y ^ { 2 } ) ^ { 1 / 2 }$ 的函数，可以表示为

$$
I(\rho,z)=I_0\left[\frac{W_0}{W(z)}\right]^2\exp\left[-\frac{2\rho^2}{W^2(z)}\right]\tag{2.3.11}
$$

其中， $I _ { 0 } = \vert A _ { 0 } \vert ^ { 2 }$ 。在任何点 $z$ 处，光强是径向距离 $\rho$ 的高斯函数，这就是高斯光束名称的由来。高斯光束在轴上点 $\rho { = } 0$ 时光强值最大，随着 $\rho$ 的增大而单调下降；同时高斯光束截面分布的宽度 $W ( z )$ 随的加大而增大，如图2-3-1所示。

对于轴上各点，即 $\rho = 0$ 时，高斯光束的光强分布为

$$
I(0,z)=I_0\left[\frac{W_0}{W(z)}\right]^2=\frac{I_0}{1+(z/z_0)^2}\tag{2.3.12}
$$

可以看出，在 $z = 0$ 处，I值最大为 $I _ { \mathrm { ~ 0 ~ } }$ ，随 $z$ 增大而下降。当 $z = \pm z _ { 0 }$ 时，光强I降至峰值的一半。如图2-3-2所示，当 $z \gg z _ { \mathrm { 0 } }$ 时， $I ( 0 , z ) \approx I _ { 0 } z _ { 0 } ^ { 2 } / z ^ { 2 }$ ，类似于球面波与抛物面波，光强按倒数平方律关系下降。峰值出现在束中心 $z = 0 , \rho { = } 0$ 处， $I ( 0 , 0 ) { = } I _ { 0 }$

## 3．束半径

在任一横截面，高斯光束的光强在轴上最强，并在 $\rho = W ( z )$ 处下降为最大值的 $1 / \mathrm { e } ^ { 2 } \approx$ 0.135，因此几乎86%的功率包含在以 $W ( z )$ 为半径的圆面积内，可定义 $W ( z )$ 为束半径或束宽度。式（2.3.6）即束半径公式。

在 $z = 0$ 处，束半径最小为 $W _ { 0 }$ ，此处称为束腰。 $W _ { 0 }$ 为束腰半径，束腰直径为 $2 W _ { 0 }$ 。束腰半径随增大而逐渐增大，在 $z = z _ { 0 }$ 到达 $\sqrt { 2 } W _ { 0 }$ 的值，随后随单调增加，当 $z \gg z _ { 0 }$ 后，式(2.3.6）中第一项可略去，有

$$
W(z)\approx\frac{W_0}{z_0}z=\theta_0z\tag{2.3.16}
$$

即在远处（远场）， $W ( z )$ 随线性增长，倾角为

$$
\theta_0=W_0/z_0=\lambda/(\pi W_0)\tag{2.3.17}
$$

定义

$$
\theta _ { 0 } = \frac { 2 } { \pi } \frac { \lambda } { 2 W _ { 0 } }\tag{2.3.18}
$$

为高斯光束的发散角，几乎86%的光功率在半角为 $\theta _ { 0 }$ 的圆截面内。光束的发散角正比于波长与束腰直径 $2 W _ { 0 }$ 之比。因此如果光束的束腰很细，则光束发散很快。如要求光束具有高的方向性，则要求波长要短，束腰要粗。 $W ( z )$ 与的关系如图2-3-3所示。

## 4.高斯光束的焦深

当光束在 $z = 0$ 点束径最小，意味着在 $z = 0$ 平面聚焦最好。偏离 $z = 0$ 点两侧向外则逐步散焦，$\pm z$ 处的束径是相同的。当束径是束腰的 $\sqrt { 2 }$ 倍，即束面积为束腰2倍时， $z = 0$ 两侧的间距为“焦深”（depthoffocus）或“共焦参量”（confocalparameter），这个距离正好是$2 z _ { 0 }$ 。如图2-3-4所示。

![](images_光电子学_教材/e7d58b0d449c431c9377875a1e6a77d9dc1b87dd25a0554d5cb503f86f1c5848_p1.jpg)  
图2-3-4高斯光束的焦深

焦深为瑞利距离的2倍，由式（2.3.9）得

$$
2z_0=\frac{2\pi W_0^2}{\lambda}\tag{2.3.19}
$$

即焦深与束腰处面积成正比，与波长成反比。当光束要求聚焦至很小光点，则焦深很小。因此很难同时获得小光点与长焦深，除非波长很小，如对于He-Ne激光，波长 $\lambda =$ 632.8nm，光点直径 $2 W _ { \circ } = 2 \mathrm { { c m } }$ 时，相应的焦深为1km；如果要求聚焦成更小的光点 $2 W _ { \mathrm { 0 } } =$ $2 0 \mu \mathrm { m }$ ,则焦深只有1mm。

## 4.1.1光子能量与不可分性

光子具有相应电磁场模式的能量，并且是离散的量子态化的能量。频率为v的光子某个模式的能量为

$$
E = h _ { 2 } = h _ { \omega }\tag{4.1. 1}
$$

其中， $h { = } 6 . 6 3 { \times } 1 0 ^ { - 3 4 } \mathrm { J s }$ 为普朗克常数， $\hbar = h / 2 \pi$ 。某个模式的电磁场（光束）是由大量光子构成的，该模式的光子能量可以相加或相减，但基本单位是 $h _ { \nu _ { c } }$ 。光子是不可分的。

然而，具有零个光子的模式的能量为 $E _ { 0 } = ( 1 / 2 ) h \nu$ ，称为零点能（zero-pointenergy）。如果某模式具有n个光子，则该模式的总能量为

$$
E _ { n } = ( n + \frac { 1 } { 2 } ) h \nu , \quad n = 0 , 1 , 2 , \cdots\tag{4.1.2}
$$

在大部分实验中，人们通常测量的是能级之间能量的差异 $( E _ { n 2 } - E _ { n 1 } )$ ，零点能是不能直接测量的。只有当物质放置在静场中时，零点能才显现出其微妙的作用，它在原子的自发辐射中起重要作用。

因为高频光子携带的能量也高，因此光子的粒子特性随着辐射频率的增大而变得更为重要。同时，频率增大，波长减小，波动特性(如干涉与衍射)就越难清晰可辨。因此X射线与γ射线的行为更趋于粒子的集合，而无线电波更具有波的行为。光子频率与波长、能量、波长倒数之间的关系如图4-1-1所示。

## 4.2.1 平均光子通量

## 1．平均光子通量密度

光强度为 $I ( r ) ( \mathrm { W / c m ^ { 2 } } )$ 频率为v的单色光，对应的平均光子通量密度为

$$
\phi ( r ) = { \frac { I ( r ) } { h \nu } }\tag{4.2.1}
$$

式（4.2.1）将经典的能量度量（能量 $/ ( \mathrm { s } \cdot \mathrm { c m } ^ { 2 } ) \cdot$ 转化为量子度量（光子数 $/ ( \mathrm { s } \cdot \mathrm { c m } ^ { 2 } ) )$ 。对于中心频率为的准单色光全体光子的能量近似等同于 $h \bar { \nu }$ ，因此平均光子通量密度为

$$
\phi ( r ) \approx { \frac { I ( r ) } { h \bar { \nu } } }
$$

## 2.平均光 $\mathrm { \dot { + } }$ 通量

平均光子通量密度对标定面积的积分，就得到单位时间通过该面积的光子数，即平均光子通量，表达式为

$$
\varPhi = \int _ { \frac { \pi } { A } } \Bigl ( r ) \mathrm { d } A = \frac { P } { h \bar { \nu } }\tag{4.2.2}
$$

因平均光子通量 $h _ { \nu }$ 是一个常数，所以光功率为

$$
P = \int _ { A } I ( \pmb { r } ) \mathrm { d } A\tag{4.2.3}
$$

例如：对于 $\lambda _ { \mathrm { 0 } } = 0 . 6 3 2 8 \mathrm { n m }$ 的光功率为1nW的光，其包含的平均光子通量为 $\Phi \approx 3 \times 1 0 ^ { 9 }$ 光子数 $/ \mathrm { s }$ ，换句话说，每一纳秒（ns）有3个光子打到探测面上。

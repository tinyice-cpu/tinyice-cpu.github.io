## 1．位相调制器

当光通过一长度为L的普克尔盒的时候，其产生的位相变化为

$$
\varphi { = } n ( E ) k _ { \circ } L { = } \frac { 2 \pi n ( E ) L } { \lambda _ { \circ } }\tag{8.1.37}
$$

其中 $k _ { 0 }$ 为波矢,E为外加电场， $\lambda _ { 0 }$ 为光波长。将式(8.1.4)代人式(8.1.37)可得

$$
\varphi { \approx } \varphi _ { \mathrm { 0 } } { - } \pi \frac { \gamma n ^ { 3 } E L } { \lambda _ { \mathrm { 0 } } }\tag{8.1.38}
$$

其中， $\varphi _ { \mathrm { 0 } } = 2 \pi n L / \lambda _ { \mathrm { 0 } } \mathrm { ~ , ~ } \gamma$ 为电光系数。如果普克尔盒上所加电压为V，间距为 $d$ 则 $E { = } V / d$ 式(8.1.38)可写为

$$
\varphi { = } \varphi _ { 0 } { - } \pi { \frac { V } { V _ { \pi } } }\tag{8.1.39}
$$

其中

$$
V _ { \pi } = \frac { d } { L } \frac { \lambda _ { 0 } } { \gamma n ^ { 3 } }\tag{8.1.40}
$$

称为半波电压，表示当外加电压为V时，位相的变化为π。由式(8.1.40)可知，半波电压和 $V _ { \pi }$ $\pi$ 材料的特性以及尺寸、光波长等有关。在普克尔盒中，位相和外加电压成线性关系，其变化曲线如图8-1-5所示。

在式(8.1.40)中，如果位相调制器为纵向调制器，则其电极间距和调制器长度相等，即$d = L$ ，其半波电压只和电光系数、波长及折射率有关。由于大多数电光材料为光学晶体，其折射率及电光系数均为各向异性，因此实际的电光系数取决于光的传播方向和外加电压的方向。

电光调制器件也经常应用于集成光学器件中，图8-1-6为集成在波导中的位相调制器，其中光波导是通过在光学晶体基板表面掺杂的方式获得。在波导两侧镀制金属电极，并施加电压。由于在集成元件中波导的宽度尺寸较小，而波导长度相对较长，因此其所加的半波电压和块状材料所做的器件相比要小得多，一般所加半波电压可以小到几伏。而其调制频率可以超过100GHz。

## 3．光强调制器

由于电光效应只是改变材料的折射率，因此它只能对光的位相、偏振态、折射角等产生影响，而不会直接对光强产生调制。光强调制器需要通过位相或位相延迟的调制，来间接实现光强的调制。

实现光强调制的第一种方法是干涉法。图8-1-7(a)为典型的马赫-曾德(Mach-Zehnder)干涉仪，在干涉仪其中的一个臂中加入一个位相调制器，则由干涉原理可知，其出射端的干涉光强为

$$
I _ { \circ } { = } \frac { 1 } { 2 } I _ { \mathrm { i } } { + } \frac { 1 } { 2 } I _ { \mathrm { i } } \ \mathrm { c o s } \varphi { = } I _ { \mathrm { i } } \ \mathrm { c o s } ^ { 2 } \ \frac { \varphi } { 2 }\tag{8.1.45}
$$

其中 $\varphi$ 为光通过干涉仪两个臂后产生的位相差。如果把整个干涉仪看成一个元部件的话，则该器件的透过率为

$$
T { = } \frac { I _ { \mathrm { o } } } { I _ { \mathrm { i } } } { = } \cos ^ { 2 } \ \frac { \varphi } { 2 }\tag{8.1.46}
$$

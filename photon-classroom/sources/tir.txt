## 八、全反射

光波从光密介质射向光疏介质（n<1）时，若增大折射角，根据折射定律

$$
\mathrm { s i n } \theta _ { 2 } = \frac { n _ { 1 } } { n _ { 2 } } \mathrm { s i n } \theta _ { 1 } > 1
$$

因不存在满足上式条件的折射角 $\theta _ { 2 }$ ，故这时没有折射光，在界面上所有的光都反射回介质$1 _ { \mathrm { ~ o ~ } }$ 这种现象称为全反射。当入射角为

$$
\mathrm { s i n } \theta _ { \mathrm { c } } = \frac { n _ { 2 } } { n _ { 1 } } = n
$$

时，折射角 $\theta _ { 2 } = 9 0 ^ { \circ }$ ，此时开始全反射，称 $\theta _ { c }$ 为临界角。下面利用菲涅耳公式讨论全反射的特点及其应用。

## （三）倏逝波

图11-18用临界角高精度对焦

面上被全部反射回第一介质，而是透入第二介质大约一个波长的深度，并沿着界面流过波长量级距离后重新返回第一介质，沿着反射光方向射出。这个沿着第二介质表面流动的波称为倏逝波。从电磁场的连续条件来看，倏逝波的存在是必然的。因为电场和磁场不会在两介质的界面上突然中断，在第二介质中应该有透射波存在，并具有特殊的形式。这从下面讨论中易知。

设取xz平面为入射面，由式（11-28），其透射波可表示为

$$
E _ { 2 } = A _ { 2 } \mathrm { e x p } \big [ \mathrm { i } k _ { 2 } \big ( x \mathrm { s i n } \theta _ { 2 } + z \mathrm { c o s } \theta _ { 2 } \big ) \big ] \mathrm { e x p } \big ( -\mathrm{i}\omega t \big )
$$

将式（11-78a）、（11-78b）代入上式，且利用 $k _ { 1 } = k _ { 2 } / n$ ，可得

$$
E _ { 2 } = A _ { 2 } \mathrm { e x p } \big [ - k _ { 1 } z \ \sqrt { \mathrm { s i n } ^ { 2 } \theta _ { 1 } - n ^ { 2 } } \big ] \mathrm { e x p } \big [ \mathrm { i } ( k _ { 1 } x \mathrm { s i n } \theta _ { 1 } - \omega t ) \big ]\tag{11-82}
$$

式中， $k _ { 1 } , ~ k _ { 2 }$ 分别为介质1和介质2中的波数。式（11-82）表明，透射波是一个沿x方向传播其振幅在z方向作指数衰减的波，这个波就是倏逝波（见图11-19）。可以看出，这是一个

非均匀波，其等幅面是z为常数的平面，其等相面是x为常数的平面，两者互相垂直，并且倏逝波的波长和传播速度分别为

$$
\lambda _ { 2 } = \frac { 2 \pi } { k _ { 1 } \sin \theta _ { 1 } } = \frac { \lambda _ { 1 } } { \sin \theta _ { 1 } }\tag{11-83}
$$

$$
v _ { 2 } = { \frac { v _ { 1 } } { \sin \theta _ { 1 } } }\tag{11-84}
$$

式（11-82)还表明，倏逝波的振幅随透入深度z的增加急速下降。通常定义振幅减少到界面 $( z = 0 )$ ）处振幅的 $1 / \mathrm { e }$ 时的深度为穿透深度 $z _ { 0 }$ ，则

$$
z _ { 0 } = { \frac { \lambda _ { 1 } } { 2 \pi \ { \sqrt { \sin ^ { 2 } \theta _ { 1 } - n ^ { 2 } } } } }\tag{11-85}
$$

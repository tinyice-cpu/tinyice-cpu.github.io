## 2.2.3球面谐振腔

球面谐振腔是由两个半径分别为 $R _ { 1 }$ 和 $R _ { 2 }$ ，相距d的球面镜组成的谐振腔，如图2-2-7所示。两个球面镜的中心连线为腔的光轴（轴），这个腔是关于光轴的圆对称。我们将球面镜的半径符号定义为：凹面镜R<0（R为负），凸面镜 $R > 0 ( R$ 为正）。可见，平面谐振腔是球面腔的一种特例 $( R _ { 1 } = R _ { 2 } = \infty )$

![](images_光电子学_教材/5350d105791c2221aea06213af40f42b5492955de98f812b1c92807214568631_p1.jpg)  
图2-2-7光线在腔内m次来回之后的 $y _ { m }$ 与角度 $\theta _ { m }$

对于近轴光束，当光线倾角角度很小时，可以近似用矩阵法计算m次光束来回之后的光线的位置与角度，表达式为

$$
{ \left[ \begin{array} { l } { y _ { m + 1 } } \\ { \theta _ { m + 1 } } \end{array} \right] } = { \left[ \begin{array} { l l } { A } & { B } \\ { C } & { D } \end{array} \right] } { \left[ \begin{array} { l } { y _ { m } } \\ { \theta _ { m } } \end{array} \right] }\tag{2.2.32}
$$

其中，来回传播的矩阵为

$$
{ \left[ \begin{array} { l l } { A } & { B } \\ { C } & { D } \end{array} \right] } = { \left[ \begin{array} { l l } { 1 } & { \ 0 } \\ { 2 / R _ { 1 } } & { \ 1 } \end{array} \right] } { \left[ \begin{array} { l l } { 1 } & { d } \\ { 0 } & { \ 1 } \end{array} \right] } { \left[ \begin{array} { l l } { \ 1 } & { \ 0 } \\ { 2 / R _ { 2 } } & { \ 1 } \end{array} \right] } { \left[ \begin{array} { l l } { 1 } & { d } \\ { 0 } & { \ 1 } \end{array} \right] }
$$

其中，等号右边第一个矩阵为半径 $R _ { 1 }$ 镜面反射矩阵，第二和四个矩阵为自由空间传播矩离d矩阵，第三个矩阵为半径 $R _ { 2 }$ 镜面反射矩阵。

在图2-2-7中，因为入射光线是向下的，所以 $\theta _ { 1 } < 0$ 。这里 $R _ { 1 } , R _ { 2 }$ 均为负，球面焦距 $f=0.5R$ 。具体的ABCD矩阵参数为： $A = 1 + 2 d / R _ { 2 } , B = 2 d ( 1 + d / R _ { 2 } ) , C = 2 / R _ { 1 } + 2 / R _ { 2 } +$ $4 d / ( R _ { 1 } R _ { 2 } ) , D = 2 d / R _ { 1 } + ( 2 d / R _ { 1 } + 1 ) ( 2 d / R _ { 1 } + 1 )$ 。

由于这是一个反复传播的周期结构，根据第9.1.2节周期型光学系统的光线谐波轨迹空间有限条件及稳定条件(见式(2.1.28)），周期场光线包络轨迹应为

$$
y _ { m } { = } y _ { \mathrm { m a x } } \sin ( m \varphi { + } \varphi _ { 0 } )\tag{2.2.33}
$$

其为有限值，因此 $\scriptstyle { \varphi = \cos ^ { - 1 } b }$ 必为实数，即必须有 $| b | \leqslant 1$ 。由式(2.1.29）,得

$$
b { = } 0 . 5 ( A { + } D ) { = } 2 ( 1 { + } d / R _ { 1 } ) ( 1 { + } d / R _ { 2 } ) { - } 1
$$

整理后得到稳定腔的条件为

$$
0 { \leqslant } ( 1 { + } d / R _ { 1 } ) ( 1 { + } d / R _ { 2 } ) { \leqslant } 1\tag{2.2.34}
$$

常用 $g _ { 1 } = 1 + d / R _ { 1 }$ 与 $g _ { 2 } = 1 + d / R _ { 2 }$ 这样的 $_ { g }$ 参数来表述上面的稳定腔判读条件，因此式(2.2.34）可改写为

$$
0 { \leqslant } { \boldsymbol { g } } _ { 1 } { \boldsymbol { g } } _ { 2 } { \leqslant } 1\tag{2.2.35}
$$

这就是腔的稳定性条件。注意：当式（2.2.35）不满足时，谐振腔是不稳定的，这就意味着，光束在腔内来回几次后容易溢出，也就是腔的损耗比较大。当 $g _ { 1 } g _ { 2 } = 1$ 或 $g _ { 1 } g _ { 2 } = 0$ 时，腔处于临界状态，又称条件稳定状态。将稳定腔条件式(2.2.35)用图2-2-8表示，可以得到各种腔在图中的位置，并依据各种腔在图内的位置确定其是否稳定。球面腔的 $g _ { 1 } , g _ { 2 }$ 参数落在非阴影区域时为稳定腔，阴影区域为非稳定腔，边界线上与原点为临界腔。我们可以分析几种较为特殊的腔型，如 $g _ { 1 } g _ { 2 } = 1$ 的腔是平面腔，也是临界腔。

【例2.1】一个光学谐振腔由两个凹面镜构成，曲率半径分别为50cm和100cm。求可以满足稳定条件的最大腔长。

解：谐振腔稳定性条件为 $0 { \leqslant } ( 1 + d / R _ { 1 } ) ( 1 + d / R _ { 2 } ) { \leqslant } 1$ 。代入 $R _ { 1 } = - 0 . 5 \mathrm { m }$ 以及 $R _ { 2 } = { }$ $- 1 \mathrm { m }$ ，得到 $0 { \leqslant } ( 1 { - } 2 d ) ( 1 { - } d ) { \leqslant } 1$ 。可以解得 $0 \leqslant d \leqslant 0 . 5$ 或者 $1 \leqslant d \leqslant 1 . 5$ ，因此满足稳定性条件d的最大值为1.5m。

对称腔是一种较常用的腔型，其特点是 $R _ { 1 } = R _ { 2 } = R$ ，所以稳定条件可以简化为： $0 \leqslant$ $- d / R { \leqslant } 2$ 。如果谐振腔对称同时 $R = d$ ，这时就称为对称共焦腔，其 ${ \boldsymbol { g } } _ { 1 } = { \boldsymbol { g } } _ { 2 } = 0$ ，位于原点。

注意：并不是说，产生激光就必须是稳定腔，非稳腔就无法产生激光。稳定条件只是意味着稳定腔损耗小，非稳腔的损耗大。

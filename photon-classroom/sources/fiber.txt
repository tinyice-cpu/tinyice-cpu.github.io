## 3.数值孔径

一束由空气入射到光纤的光线，只有在其折射到纤芯内的光线与光纤轴线夹角θ小于 $\overline { { \theta } } _ { \mathrm { c } }$ 时才能沿光纤传播。根据斯涅尔定律(Snell'slaw)，在空气-纤芯交界面上，对应于纤芯中的$\overline { { \theta } } _ { \mathrm { c } }$ ，空气中的角度 $\theta _ { \mathrm { a } }$ 须满足 $1 \cdot \mathrm { s i n } \theta _ { \mathrm { a } } { = } u \cdot \mathrm { s i n } \overline { { \theta } } _ { \mathrm { c } }$ （见图3-2-4），这是由 $\sin \theta _ { \mathrm { a } } = n _ { 1 } ( 1 - \cos ^ { 2 } \ \overline { { \theta } } _ { \mathrm { c } } ) ^ { 1 / 2 } =$ $n _ { 1 } [ 1 - ( n _ { 2 } / n _ { 1 } ) ^ { 2 } ] ^ { 1 / 2 } = ( n _ { 1 } ^ { 2 } - n _ { 2 } ^ { 2 } ) ^ { 1 / 2 }$ 推导出的。因此

$$
\theta _ { \mathrm { a } } = \sin ^ { - 1 } \mathrm { N A }\tag{3.2.2}
$$

其中

$$
\mathrm { N A } { = } ( n _ { 1 } ^ { 2 } { - } n _ { 2 } ^ { 2 } ) ^ { 1 / 2 } { \approx } n _ { 1 } ( 2 \Delta ) ^ { 1 / 2 }\tag{3.2.3}
$$

称为光纤的数值孔径。 $\theta _ { \mathrm { a } }$ 为光纤的接收角，它决定了能够在光纤中传播的外界光线的接收锥。所有以比 $\theta _ { \mathrm { a } }$ 大的角度入射到光纤端面的光线都可以折射入光纤，但只能传播很小的距离。数值孔径由此可以用来描述光纤耦合光的能力。

【例3.1】计算二氧化硅光纤的数值孔径和接收角，其中 $n _ { 1 } = 1 . 4 7 5 , n _ { 2 } = 1 . 4 6 0$

解：数值孔径为： $\mathrm { N A } { = } ( n _ { 1 } ^ { 2 } { - } n _ { 2 } ^ { 2 } ) ^ { 1 / 2 } { = } ( 1 . 4 7 5 ^ { 2 } { - } 1 . 4 6 0 ^ { 2 } ) ^ { 1 / 2 } { = } 0 . 2 1$

接收角为： $\theta _ { \mathrm { a } } = \sin ^ { - 1 } \mathrm { N A } = 1 2 . 1 ^ { \circ }$

当传播的光线到达光纤输出端，它们重新被折射出来，形成一个角度为 $\theta _ { \mathrm { a } }$ 的圆锥。因此接收角 $\theta _ { \mathrm { a } }$ 是光纤耦合与输出系统设计中的一个关键参数。

## 2.V参数

定义归一化 $k _ { \mathrm { ~ T ~ } }$ 与y

$$
X { = } k _ { \mathrm { { T } } } a\tag{3.2.12a}
$$

$$
Y = \gamma a\tag{3.2.12b}
$$

则式（3.2.11)可变为

$$
X ^ { 2 } + Y ^ { 2 } = V ^ { 2 }\tag{3.2.13}
$$

其中， $V { = } \mathrm { N A } \cdot k _ { \mathrm { o } } a$

$$
V = 2 \pi { \frac { a } { \lambda _ { \scriptscriptstyle 0 } } } \mathrm { N A }\tag{3.2.14}
$$

可以看到， $\mathbf { \Omega } , V$ 是个非常重要的参数，它决定了光纤的模式数量及传播常数，因此，它又被称为光纤参数或V参数（归一化频率）。光波若能在光纤中传播，X值必小于V。

## 3.2.3单模光纤

满足 $V { = } 2 \pi ( a / \lambda _ { \mathrm { 0 } } ) \mathrm { N A } { < } 2 . 4 0 5$ 的光纤为单模光纤（见表3-2-1)。通过使用小的纤芯或小的数值孔径或者选择较长的工作波长，都可以使光纤工作在单模状态。基模拥有钟形光场空间分布，与高斯光束类似（见图3-2-6(a)与图3-2-8(a)），同时还具有如图3-2-11（b)所示的由V决定的传播常数。基模是所有模式中光能量在纤芯中最为集中的模式。

光通信系统中单模光纤的优势非常明显。由于多模光纤不同模式的群速度不同，时间延迟也不同，所以一个多模短脉冲各分量的延迟不同，从而在时间上扩展开来导致脉冲变形。模式色散的定量测量将在第3.3节中讨论。而在单模光纤中，只有一个模式，一种群速度，因此一束短脉冲不会因为受到延迟而变形。第3.3.2节会进一步指出，一些其他色散效应会造成单模光纤中的脉冲展宽，然而这些展宽与模式色散造成的展宽相比是微不足道的。第3.3节还会证明，单模光纤中能量的衰减率要比多模光纤小。更小的能量衰减率和更小的脉冲展宽使得单模光纤可以允许更高的数据传输率。

多模光纤的另一个弱点来源于模式之间的随机干涉。无法控制的缺陷、应力、温度漂移都有可能造成某一个模式随机的位相移动，从而使所有复振幅的总和具有随机的扰动。这种随机扰动以噪声的形式出现，被称为模间噪声或斑点噪声。这种效应类似于由于多重路径传播而造成的射频信号的减弱。在单模光纤中由于只有一条路径，所以没有模间噪声。

由于小的尺寸以及小的数值孔径，单模光纤更适用于集成光学，但是这些特性也使得单模光纤在与可拆卸的连接器进行衔接和耦合时需要更高的精度，从而增加了制造与工作时的难度。

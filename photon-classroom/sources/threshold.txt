## 5.2.2激光振荡条件

为实现激光振荡，必须满足增益和位相两个条件。增益条件决定了所需的最少的反转

粒子数，并因此决定了激光振荡需要的泵浦阈值；位相条件决定了激光振荡时的频率。

## 1.增益条件：激光阈值

激光振荡的启动必须满足小信号增益系数大于损耗系数，即

$$
\gamma _ { \mathrm { 0 } } \left( 2 \right) > \alpha _ { \mathrm { r } }\tag{5.2.8}
$$

按照式(5.1.4），小信号增益系数 $\gamma _ { \scriptscriptstyle 0 } ( { \boldsymbol \cdot } )$ 正比于平衡粒子数密度差 $N _ { 0 }$ ，而从第5.1.1节可知，$N _ { 0 }$ 又随着泵浦速率R增加，因此根据式（5.1.4）可以将式（5.2.8）转化成粒子数差的条件，即 $N _ { 0 } = \gamma _ { 0 } ( 2 ) / \sigma ( 2 ) \geq \alpha _ { \mathrm { r } } / \sigma ( 2 )$ 。所以有

$$
N _ { 0 } > N _ { t }\tag{5.2.9}
$$

其中

$$
N _ { \mathrm { t } } { = } \frac { \alpha _ { \mathrm { r } } } { \sigma ( { \nu } _ { } ) }\tag{5.2.10}
$$

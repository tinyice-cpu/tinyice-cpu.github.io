## 3.4.2色散

当脉冲光在光纤中传播时，由于光纤的色散效应，它的功率会在时间上被“分散”，使光脉冲拉长到更大的时间间隔。在光纤中存在四种机理的色散效应：模式色散、材料色散、波导色散以及非线性色散。

## 1．模式色散

模式色散是由于不同模式群速度的差异而引发的色散，只存在于多模光纤。单个在$z = 0$ 点射入光纤的脉冲光会随着值的不同而分裂成具有不同延迟的M个脉冲。对于长度为L的光纤，不同模式所经历的时间延迟分别是 $\tau _ { q } = L / v _ { q } , q = 1 , 2 , \cdots , M , v _ { q }$ 是q模的群速度。假设 $ { v _ { \mathrm { m i n } } }$ 和 $\mathcal { V } _ { \mathrm { m a x } }$ 是最小和最大的群速度，则接收到的光脉冲宽度为 $L / v _ { \operatorname* { m i n } } - L / v _ { \operatorname* { m a x } }$ 。由于模式并不是等量触发的，接收到的脉冲具有平滑的轮廓，如图3-4-4所示。总的均方根脉冲宽度为 $\sigma _ { \tau } = ( 1 / 2 ) ( L / v _ { \mathrm { m i n } } - L / v _ { \mathrm { m a x } } )$ ，这个宽度代表光纤的响应时间。

图3-4-4模式色散引起的脉冲展宽

在一个有大量模式存在的阶跃光纤中， $v _ { \operatorname* { m i n } } \approx c _ { 1 } \left( 1 - \Delta \right) ; v _ { \operatorname* { m a x } } \approx c _ { 1 }$ （见图3-3-9(a)）。由于 $( 1 - \Delta ) ^ { - 1 } \approx 1 + \Delta$ ，则响应时间为

$$
\sigma _ { \tau } \approx \frac { L } { c _ { 1 } } \ : \frac { \Delta } { 2 }\tag{3.4.4}
$$

即它是时间延迟 $L / c _ { 1 }$ 的 $\Delta / 2$ 倍。

由于群速度得到平衡，渐变折射率光纤模式色散远比阶跃光纤小，不同模式的延迟时间 $\tau _ { q } = L / v _ { q }$ 之间的差异被缩小了。如图3-3-9（b）所示，在一根具有大量模式数目和优化折射率曲线的渐变折射率光纤中， $v _ { \mathrm { m a x } } \approx c _ { 1 } , v _ { \mathrm { m i n } } \approx c _ { 1 } ( 1 - \Delta ^ { 2 } / 2 )$ ，响应时间为

$$
\sigma _ { \tau } \approx \frac { L } { c _ { 1 } } \frac { \Delta ^ { 2 } } { 4 }\tag{3.4.5}
$$

比阶跃光纤小了 $\Delta / 2$ 倍。

不管是渐变折射率光纤还是阶跃光纤，由模式色散所引起的脉冲展宽均正比于光纤的长度 $L _ { \mathrm { ~ o ~ } }$ 但是，由于模式间的耦合，这一关系当光纤超过一定长度时，有可能不再成立。由于光纤中微小的缺陷（光纤端面随机的不规则性，或者折射率的不均匀性），具有大致相同传播常数的模式会耦合起来，从而允许光功率在不同模式间互相交换。在一定情况下，模式耦合光纤的响应时间 $\sigma _ { \tau }$ 在光纤长度L较小时正比于L，在L超过一个临界值时则正比于 $L ^ { 1 / 2 }$ 从而减小了脉冲展宽的速率。

## 2.材料色散

光纤材料的折射率随波长改变的现象，称为材料色散。一个光脉冲在折射率为n的色散介质中传播，其群速度 $v = c _ { 0 } / N , N = n - \lambda _ { 0 } \mathrm { d } n / \mathrm { d } \lambda _ { 0 }$ 。由于脉冲是一个包含不同群速度和波长的波包，它的脉冲展宽会被扩展。一个具有 $\sigma _ { \lambda } \left( \mathrm { n m } \right)$ 光谱宽度的入射光脉冲，在传播了距离L之后，其脉冲宽度为 $\sigma _ { \tau } = \mid ( \mathrm { d } n / \mathrm { d } \lambda _ { 0 } ) ( L / v ) \mid \sigma _ { \lambda } = \mid ( \mathrm { d } n / \mathrm { d } \lambda _ { 0 } ) ( L N / c _ { 0 } ) \mid \sigma _ { \lambda }$ ，从而得到

$$
\sigma _ { \tau } = \mid D _ { \lambda } \mid \sigma _ { \lambda } L\tag{3.4.6}
$$

其中

$$
D _ { \lambda } = - \frac { \lambda _ { 0 } } { c _ { 0 } } \frac { \mathrm { d } ^ { 2 } n } { \mathrm { d } \lambda _ { 0 } ^ { 2 } }\tag{3.4.7}
$$

是材料色散系数。响应时间随距离L线性增加。通常L的单位是 $\mathrm { k m } , \sigma _ { \tau }$ 的单位是 $\mathrm { p s } , \sigma _ { \lambda }$ 的单位是nm，因此 $D _ { \lambda }$ 具有单位ps/（km·nm）。这种色散称为材料色散(与模式色散相对应）。

## (3)受激辐射

## 4.4.3受激辐射和吸收

## 1．单频光跃迁

下面讨论单频的光子流和原子之间的相互作用。假定单频光的频率为v，光强为I,则平均光子流密度（单位为光子数 $/ ( \mathrm { c m } ^ { 2 } \cdot \mathrm { s } ) )$ 为

$$
\phi = \frac { I } { h _ { 2 } }\tag{4.4.14}
$$

参与相互作用过程的光子数n可以通过构造一个圆柱体来计算，假设圆柱体底面为A，高度为c,圆柱体的轴与光传播方向平行(传播矢量为k)。故圆柱体的体积为 $V = c A$ ，穿过圆柱体底面的光通量为A（每秒光子数）。因为光子的速度为c，即一秒钟内圆柱体内的所有光子数都会穿过圆柱体底面，所以某时刻圆柱体包含光子数 $n = \phi A$ ，或

$$
n = \phi { \frac { V } { c } }\tag{4.4.15}
$$

于是 $\phi = ( c / V ) n$ 。因为 $\boldsymbol { W } _ { \mathrm { i } } = n \frac { c } { V } \boldsymbol { \sigma } ^ { ( \nu ) }$ ，把式（4.4.15）代人即得

$$
W _ { \textrm { i } } = \phi \sigma ( { \textrm { \em { \rho } } } _ { 2 } )\tag{4.4.16}
$$

其中， $\sigma ( \nu )$ 为受激跃迁的概率密度和光子流密度的比例系数，也称为“受激发射截面”，由于$\phi$ 为每平方厘米的光通量， $\sigma ( \nu )$ 是有效原子截面积 $( \mathrm { c m } ^ { 2 } )$ ，所以 $\phi _ { \sigma } ( \nu )$ 是原子为了吸收或受激辐射而“捕获”的光通量。

原子的衰减会增强自发辐射速率，而受激辐射只与光子的衰减有关，只有大量的光子才能增强受激辐射的速率。

# 光知 · AI 光电子学课堂

一套可离线打开的课程演示网站。打开 `index.html` 即可，无需构建和后端。

## 功能

- 全书知识地图：9 章、142 个节级目录条目，保留教材印刷页码和 Markdown 行号。
- 9 个章节代表演示：系统信息链、高斯光束、光纤接收、光子通量、激光阈值、带隙门槛、光电探测、电光调制、倍频相位匹配。
- 课程资料库：660 段教材内容和 134 页课程课件文字，支持本地全文词项检索。
- 课件专题演示：高斯光束和谐振腔，精选课件原页可放大。
- 6 个完整互动实验、14 份详细课堂活动、概念诊断示例。

## 演示说明

检索和参数计算在浏览器真实运行。导读、讲解、追问与反馈是预置教学示例，没有调用实时大模型。动画采用各页面注明的简化物理模型，不是实验测量数据。

课程原文来自用户整理的《光电子学》Markdown，课件来自用户提供的两份课程 PDF。源码中的目录与提取文字可能存在 OCR 误差，重要公式应核对原资料。目录覆盖全书，不表示每个条目都有独立仿真或完整备课讲稿。

本目录所有脚本、样式、索引和图片使用相对路径，可部署在 GitHub Pages 的子目录。

# 光知课程：按教材组织的学习与备课空间

这次改版把“知识库、问答、实验、教师工具”的并列功能入口，改成以章节为主线的课程界面。学生先找到正在学习的小节，再在同一页完成阅读、观察和检验。

## 页面结构

- 课程学习：左侧为全书 9 章、142 个节级目录；右侧为当前小节。
- 课程资料：检索 660 段教材与 134 页课件文字，保留来源位置，并提供原始课件 PDF。
- 学习记录：记录本浏览器的作答、笔记和学过标记。

每节课包含“本节导学 → 教材与公式 → 课件与讲稿 → 原理实验 → 检验与笔记”。没有专属实验的小节明确说明，不给每一节机械附加无关实验。

## 师生关系

右上角切换学生学习与教师备课。切换保留当前小节，师生均可阅读共享教材、课件、讲稿与实验。教师视角额外提供教学目标、备课备注和本机作答反馈。

这是演示用视角切换，不是账号权限系统。备课草稿、学习记录保存在当前浏览器，不会同步到学生设备；共享讲稿来自网站已发布的课程内容。

## 公式与资料范围

原来的正文摘要会将数学表达式替换成占位符。新版直接读取整理稿并用本地 KaTeX 排版，保留原始 Markdown 和 506 幅原图；字体和图片均可离线使用。

整理稿 5,417 处数学表达式中，5,407 处通过排版语法检查，10 处原稿语法损坏保留原文并标注待校对。排版检查不等同于物理内容全面校对。平面谐振腔小节的 90 处表达式已通过浏览器检查。

已导入的教师原始课件是课程导论 25 页及光波课件 109 页。其他章节保留教材与教学组织示例，不冒充已有完整教师课件。网站未连接实时大模型，知识库为本地全文检索。

## 推荐三分钟展示

1. 打开 2.2.1 平面谐振腔，展示“教材与公式”，说明出处可核对。
2. 切到“课件与讲稿”，打开原课件第 25–27 页，展示教师材料对学生开放。
3. 进入“原理实验”，将腔长从 15 cm 改为 30 cm，观察纵模间隔减半；单步观察节点不随时间移动。
4. 切换教师视角，展示备课备注，再返回学生视角。
5. 有时间可进入 4.4 比较三种光子过程，或 8.1 展示相位改变如何成为亮暗变化。

差异化表达：“以自己的教材和课件为依据，学生沿章节学习，把公式放回物理过程；教师用同一份课程内容组织预测、观察与追问。”

# 私密课堂使用说明

## 明天展示

双击“打开私密课堂.html”，仍进入原光电子学课堂推演首页，品牌和题目保留。顶部新增“物理光学”入口。

本机也可双击“启动私密课堂.cmd”，通过只监听本机的 http://127.0.0.1:8766/ 阅读；此方式已完成浏览器实测。脚本复用已安装的 Node.js，不修改执行策略或安装软件。若系统限制脚本运行，使用 HTML 入口即可。

直接学习物理光学时，双击“打开物理光学.html”。不用联网，也不必启动服务器。复制到其他电脑时，请复制整个私密包，解压后再打开，不要单独复制 HTML 文件。

物理光学按主教材第十一至十七章的 47 个小节排列。选择小节后，可点击对应的梁书章节；两侧独立翻页，页码显示 PDF 页序及书内页码。可以收起目录、切为单本阅读、点击原页放大，或打开完整原 PDF。搜索两本书使用已有 OCR；原页保留公式与图示。未直接对应的内容明确标注。

笔记按小节保存在当前浏览器，可以导出 Markdown 备份。双击文件与 localhost 属于不同浏览器来源，笔记不自动互通；更换浏览器或清理数据前请导出。

## 当前隐私状态

2026-09-21 用户要求整个网站仅本人可见。GitHub 仓库 tinyice-cpu/tinyice-cpu.github.io 已设为 private。未登录访问个人主页、课堂主页和仓库接口返回 404。原 Pages 配置已备份在 privacy-before.json；改变仓库私密性使公开站点不可访问。

现在只能在本机打开，原公开网址不再提供课堂页面。私有仓库可在登录本人 GitHub 账号后访问；这不等于原网址变成了带登录的学习网站。

本地服务 preview-private.cjs 只监听 127.0.0.1:8766，拒绝非本机 Host；默认不开放给局域网。它不是在线账号系统。同一电脑上能访问你的文件或浏览器的人仍可能阅读本地资料。

private-dist 是本机私密构建；dist 保留原光电子学构建。publish-github.ps1 已添加 privacy-lock.json 检查，防止误恢复公开。未经新的明确授权，不得撤销此限制或将 private-dist 上传公开托管。

以前公开期间已被他人保存的副本无法通过关站追回。需要跨设备网址访问时，应另行部署由服务端验证本人身份的站点，并将教材、原图、PDF、搜索数据一并纳入访问控制。
